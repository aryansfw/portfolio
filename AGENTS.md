# Portfolio Blog Context

## Goal

Build an application-ready frontend portfolio from Vercel's Next.js portfolio/blog starter. Projects are the primary proof of work; writing supports them.

## Product shape

- Next.js App Router, TypeScript, Tailwind CSS, and local MDX posts.
- Homepage: concise introduction, featured projects, latest writing, contact links.
- Projects page: three case studies using problem, approach, stack, and outcome.
- Blog: practical articles tied to project work.
- Deploy to Vercel; preserve metadata, sitemap, robots, RSS, and OG image support.

## Constraints

- Keep the implementation small and accessible.
- Reuse starter components and native Next.js features.
- No CMS, database, authentication, comments, filtering, or search unless requested.
- Personal details and unknown project facts stay as obvious placeholders rather than invented claims.

## Commands

- `pnpm dev`
- `pnpm build`

## Before publishing

Search for `TODO:` and replace the name, summary, email, social links, domain, resume URL, and placeholder project facts.
