## From event information to action

The public landing pages led into bootcamp and seminar registration flows. I connected those pages to payment-proof uploads and participant-facing status updates so visitors could continue from information to registration.

I kept that path understandable on desktop and mobile screens.

## Keeping registration steps valid

The registration flow validates each step before moving forward. That prevents incomplete personal data or payment details from being hidden by a later screen.

This simplified example shows the guard between steps:

```ts
function handleNext() {
  trigger(fieldsForStep[currentStep], { shouldFocus: true }).then((valid) => {
    if (valid) setCurrentStep((step) => step + 1)
  })
}
```

The form keeps its state across steps, then submits as `FormData` on the final screen.

## Supporting the operations team

The platform also needed administration workflows for reviewing participant information and registration status. I built the participant detail and review screens so staff could update a submission from the same workflow.

I also reviewed frontend work from three staff members, which helped keep implementation and interface quality consistent as the platform grew.

The admin flow exposed explicit payment states, so each reviewer action mapped to one backend status.

This simplified example shows that mapping:

```ts
const paymentActions = {
  verified: () => updatePaymentStatus("verified"),
  need_revision: () => updatePaymentStatus("need_revision"),
  rejected: () => updatePaymentStatus("rejected"),
}
```

## What I took from it

The project showed me that public pages, registration, document submission, and review screens need to share one flow. Participants may start and finish on different devices, so responsive behavior belongs in the workflow from the beginning.

## Result

I contributed frontend features and API-integrated workflows across the event platform. The public site remains available at [schematics-23.vercel.app](https://schematics-23.vercel.app/).
