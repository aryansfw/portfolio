# Anti-slop audit 001

Scope: the deployed portfolio after the domain update. This is an audit only; no findings have been changed.

1. **HIGH, R-02**: `app/page.tsx` and `app/og/route.tsx` use an em dash in public text. Replace it with a permitted separator.
2. **HIGH, R-35**: A complete interactive and mobile click-through has not been recorded. Build verification passed, but the homepage, projects, blog posts, external links, light/dark modes, and mobile layout still need browser verification.
3. **HIGH, R-37**: No design direction or explicit ENERGY/RHYTHM/MOTION dials are documented. The current starter-derived visual language cannot be approved as a final design without that direction.
4. **MEDIUM, R-20**: The portfolio has no stated visual identity beyond the starter's neutral presentation. Define a portfolio-specific identity before visual polish.
5. **MEDIUM, R-31**: Major visual choices (typeface, palette, card layout, spacing, and dark-mode behavior) have no documented rationale.
