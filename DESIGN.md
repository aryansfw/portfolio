# Design direction

Identity: personal frontend portfolio.

Visual language: bold and studio-like.

Dial: ENERGY 3 / RHYTHM 3 / MOTION 1.

Reason: the portfolio should make the work feel distinctive through strong hierarchy and varied composition, without decorative animation competing with project evidence.

Palette: neutral canvas with a restrained cobalt accent.

Typography: a large, tight homepage introduction creates the page focal point while preserving a readable system font.

Project cards: sequential indices make the project list read as an authored body of work, and the cobalt accent guides scanning without adding decoration.
